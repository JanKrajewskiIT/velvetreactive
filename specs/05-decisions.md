# Compatibility Decision Register

## Purpose

The source contains observable edge behavior that is unsafe, surprising, or inconsistent with the apparent public intent. It must not silently become either a permanent compatibility promise or an unannounced breaking change.

The user accepted all recommendations. Each `USER accepted` resolution below is authoritative and overrides conflicting `SOURCE` requirements in tasks 01-04. Legacy evidence remains only to explain the compatibility change.

## Implementation Rule

Implement every accepted resolution. Where an accepted resolution changes a public type, state transition, error, timing rule, or side effect described elsewhere, this file takes precedence. Internal structure remains unconstrained.
